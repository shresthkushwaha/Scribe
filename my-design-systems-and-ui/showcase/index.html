EDGE CASE RECOVERY

Offline Fallback Recovery System

When AI synthesis fails (missing key, network drop, quota limit), Scribe never crashes. It instantly generates a deterministic structural graph and displays a recovery HUD.

Offline Recovery HUD Banner (Top of Canvas) Auto-triggered on failure
Offline Fallback Graph
HEURISTIC MODE

Map built deterministically from markdown headings, bullet points, and paragraphs. Zero API calls. Zero latency (<5ms).

● AI MODE RESTORED

After saving BYOK key, map auto-reconstructs with Gemini 2.5 Flash synthesis. No page refresh required.

Failure Recovery Decision Tree
synthesize() ──▶ API call fails?
├── HTTP 403/400 ──▶ Heuristic graph + BYOK HUD
├── HTTP 429 ──▶ Heuristic graph + quota notice
├── OFFLINE ──▶ Heuristic graph + reconnect toast
├── Empty JSON ──▶ safeJsonParse() + heuristic fallback
└── No key ──▶ Immediate heuristic (0ms) + BYOK prompt
